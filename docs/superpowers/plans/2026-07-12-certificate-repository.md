# Certificate Repository Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Certificate Repository — committee uploads a PDF certificate for a participant who was marked `PRESENT` at an event, the participant downloads their own via a short-lived signed URL, private storage throughout — as a new shared `storage` module plus a new `certificates` module.

**Architecture:** New `backend/src/storage/` module: `StorageService` wraps `@aws-sdk/client-s3` (pointed at MinIO) + `@aws-sdk/s3-request-presigner`, exposing `putObject`/`getSignedDownloadUrl`/`deleteObject`. New `backend/src/certificates/` module: `CertificatesService` (upload validation pipeline + list/findMine/download/remove) and `CertificatesController` (5 routes under `/organizations/:orgId/events/:eventId/certificates`, multipart upload via `FileInterceptor`). `CertificatesModule` imports `StorageModule` — one-directional dependency, no cycle. `Certificate` rows are independent of the `Attendance`/`Registration` transaction chain (unlike QR attendance): upload is a standalone action gated by *reading* an existing `PRESENT` `Attendance` row, not by participating in its lifecycle.

**Tech Stack:** NestJS 10, Prisma 5, PostgreSQL 16, `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner` (MinIO), `multer` via `@nestjs/platform-express`'s `FileInterceptor`, Jest + Supertest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-12-certificate-repository-design.md` (as amended by commit `a59ac42` — read the current file, not memory of an earlier version).
- **Deterministic storage key**: `certificates/{organizationId}/{eventId}/{userId}.pdf`. One certificate per person per event (`@@unique([eventId, userId])`).
- **Upload validation order (must match exactly):** (1) org-scoped `Event` lookup → `404` if wrong org/event; (2) file present, MIME `application/pdf`, size ≤ 5MB → `400`; (3) target user has `Attendance.status === 'PRESENT'` for this event → `400`; (4) pre-check no existing `Certificate` row for this event+user → `409` if one exists, **before any storage write**; (5) live quota check (`SUM(fileSizeBytes)` for the org + new file size vs `Organization.storageQuotaMb`) → `400` if exceeded; (6) `StorageService.putObject`; (7) `Certificate.create` — if this still throws `P2002` (narrow concurrent-race residual), return `409` directly, **never delete the storage object** (shared key — a losing request can't distinguish its own bytes from the winner's).
- No new role group — every route except `/me` uses `MANAGE_EVENTS`; `/me` is `TenantGuard`-only (any org member), matching the `attendance`/`registrations` `/me` pattern.
- Signed download URLs: `StorageService.getSignedDownloadUrl(key, 300)` (5 min), generated fresh per request, never stored.
- Multer's `FileInterceptor` limit is set to 10MB (abuse ceiling only) — the real 5MB cap is enforced explicitly in the service so the error is a clean `400`, not multer's generic rejection.
- Audit metadata is ids only: `certificate.upload {certificateId, eventId, userId}`, `certificate.delete {certificateId, eventId, userId}`.
- `S3_BUCKET` env var is new but is **not** added to the Joi `envValidationSchema` — matches the existing convention for `S3_ENDPOINT`/`S3_ACCESS_KEY`/`S3_SECRET_KEY`, which are already present in `.env.example` and consumed via `ConfigService` without fail-fast validation. Do not touch `env.validation.ts` or `env.validation.spec.ts` in this plan.
- Tenant isolation is mandatory: `Certificate` added to `TENANT_SCOPED_MODELS`; every mutation self-scopes `where: { id, organizationId }` manually (the `$use` middleware covers `findFirst`/`findMany`/`updateMany`/`deleteMany`/etc., not single-row `update`/`delete` — see `tenant-scope.middleware.ts`'s `SCOPED_ACTIONS` set).
- Never trust client-supplied `organizationId`/`storageKey`/`fileSizeBytes`/`uploadedByUserId` — DTOs never expose them; global `ValidationPipe({ whitelist: true, transform: true })` strips extras.
- Org names in e2e fixtures must be ≥2 chars (`CreateOrganizationDto @MinLength(2)`).
- TDD: red → green → refactor. All existing suites stay green (baseline on `main`: unit 35, e2e 127 committed / 128 with the user's untracked `zzz-concurrency-probe.e2e-spec.ts` — leave that file and the user's uncommitted `.gitignore` change untouched throughout). Docker Postgres + MinIO must be running for e2e (and for the storage unit test in Task 2, which hits real MinIO).
- Prisma client is regenerated by `npx prisma migrate dev`; import enums/types from `@prisma/client`.
- Node 24 in this environment ships a global `fetch` — usable directly in Jest tests without an extra HTTP client dependency.

// backend/src/storage/storage.service.ts
import { Injectable, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import {
  CreateBucketCommand,
  DeleteObjectCommand,
  GetObjectCommand,
  PutObjectCommand,
  S3Client,
} from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

@Injectable()
export class StorageService implements OnModuleInit {
  private readonly client: S3Client;
  private readonly bucket: string;

  constructor(private readonly config: ConfigService) {
    this.bucket = this.config.get<string>('S3_BUCKET', 'ucm-dev');
    this.client = new S3Client({
      endpoint: this.config.get<string>('S3_ENDPOINT'),
      region: 'us-east-1',
      forcePathStyle: true,
      credentials: {
        accessKeyId: this.config.get<string>('S3_ACCESS_KEY')!,
        secretAccessKey: this.config.get<string>('S3_SECRET_KEY')!,
      },
    });
  }

  // Idempotent: MinIO doesn't auto-create buckets. Swallow the
  // already-exists case; anything else is a real startup failure.
  async onModuleInit() {
    try {
      await this.client.send(new CreateBucketCommand({ Bucket: this.bucket }));
    } catch (error: any) {
      const code = error?.Code ?? error?.name;
      if (code !== 'BucketAlreadyOwnedByYou' && code !== 'BucketAlreadyExists') {
        throw error;
      }
    }
  }

  async putObject(key: string, buffer: Buffer, contentType: string): Promise<void> {
    await this.client.send(
      new PutObjectCommand({ Bucket: this.bucket, Key: key, Body: buffer, ContentType: contentType }),
    );
  }

  getSignedDownloadUrl(key: string, expirySeconds: number): Promise<string> {
    return getSignedUrl(this.client, new GetObjectCommand({ Bucket: this.bucket, Key: key }), {
      expiresIn: expirySeconds,
    });
  }

  async deleteObject(key: string): Promise<void> {
    await this.client.send(new DeleteObjectCommand({ Bucket: this.bucket, Key: key }));
  }
}
```

// backend/src/certificates/certificates.service.ts
import { BadRequestException, ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { Prisma } from '@prisma/client';
import { PrismaService } from '../prisma/prisma.service';
import { StorageService } from '../storage/storage.service';
import { AuditService } from '../audit/audit.service';

const ALLOWED_MIME = 'application/pdf';
const MAX_FILE_BYTES = 5 * 1024 * 1024;
const SIGNED_URL_TTL_SECONDS = 300;

type UploadedFile = { mimetype: string; size: number; buffer: Buffer };

@Injectable()
export class CertificatesService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly storage: StorageService,
    private readonly audit: AuditService,
  ) {}

  async upload(
    organizationId: string,
    eventId: string,
    targetUserId: string,
    file: UploadedFile | undefined,
    actorUserId: string,
  ) {
    const event = await this.prisma.event.findFirst({ where: { id: eventId, organizationId } });
    if (!event) throw new NotFoundException('Event not found in this organization');

    if (!file) throw new BadRequestException('A file is required');
    if (file.mimetype !== ALLOWED_MIME) throw new BadRequestException('Only PDF files are accepted');
    if (file.size > MAX_FILE_BYTES) throw new BadRequestException('File exceeds the 5MB limit');

    const attendance = await this.prisma.attendance.findFirst({
      where: { eventId, organizationId, status: 'PRESENT', registration: { userId: targetUserId } },
    });
    if (!attendance) throw new BadRequestException('Target user was not marked present for this event');

    // Pre-check before any storage write: the storage key is deterministic
    // and shared across every upload attempt for this event+user, so a
    // duplicate write here would silently overwrite the first (already
    // successful) certificate's bytes. See the design spec's upload
    // validation order for the full reasoning.
    const existing = await this.prisma.certificate.findFirst({ where: { eventId, organizationId, userId: targetUserId } });
    if (existing) throw new ConflictException('A certificate already exists for this person and event');

    const organization = await this.prisma.organization.findUnique({ where: { id: organizationId } });
    const usage = await this.prisma.certificate.aggregate({
      where: { organizationId },
      _sum: { fileSizeBytes: true },
    });
    const usedBytes = usage._sum.fileSizeBytes ?? 0;
    const quotaBytes = organization!.storageQuotaMb * 1024 * 1024;
    if (usedBytes + file.size > quotaBytes) {
      throw new BadRequestException('Organization storage quota exceeded');
    }

    const storageKey = `certificates/${organizationId}/${eventId}/${targetUserId}.pdf`;
    await this.storage.putObject(storageKey, file.buffer, ALLOWED_MIME);

    try {
      const certificate = await this.prisma.certificate.create({
        data: {
          eventId, organizationId, userId: targetUserId,
          storageKey, fileSizeBytes: file.size, uploadedByUserId: actorUserId,
        },
      });
      await this.audit.record({
        organizationId, actorUserId, action: 'certificate.upload',
        targetType: 'Certificate', targetId: certificate.id,
        metadata: { certificateId: certificate.id, eventId, userId: targetUserId },
      });
      return certificate;
    } catch (error) {
      // Narrow residual race the pre-check above doesn't fully close (two
      // uploads for the same event+user landing within the same instant).
      // Do NOT delete the storage object here — the key is shared, and a
      // losing request can't tell its own bytes apart from the winner's.
      if (error instanceof Prisma.PrismaClientKnownRequestError && error.code === 'P2002') {
        throw new ConflictException('A certificate already exists for this person and event');
      }
      throw error;
    }
  }
}

  async remove(organizationId: string, eventId: string, certificateId: string, actorUserId: string) {
    const certificate = await this.prisma.certificate.findFirst({ where: { id: certificateId, organizationId, eventId } });
    if (!certificate) throw new NotFoundException('Certificate not found in this event');

    await this.storage.deleteObject(certificate.storageKey);
    try {
      await this.prisma.certificate.delete({ where: { id: certificateId, organizationId } });
    } catch (error) {
      if (error instanceof Prisma.PrismaClientKnownRequestError && error.code === 'P2025') {
        throw new NotFoundException('Certificate not found in this event');
      }
      throw error;
    }

    await this.audit.record({
      organizationId, actorUserId, action: 'certificate.delete',
      targetType: 'Certificate', targetId: certificateId,
      metadata: { certificateId, eventId, userId: certificate.userId },
    });
    return { removed: true as const };
  }
```

  async function registerAndLogin(email: string) {
    await request(app.getHttpServer()).post('/auth/register').send({ email, password: 'password123', fullName: email });

    eventAId = eventA.body.id;
    await request(app.getHttpServer()).post(`/organizations/${orgAId}/events/${eventAId}/publish`)
      .set('Authorization', `Bearer ${presAToken}`).expect(200);

    const participantEmail = `iso-p-${Date.now()}@test.io`;
    const participantToken = await registerAndLogin(participantEmail);

      .post(`/organizations/${orgAId}/events/${eventAId}/registrations`)
